# Compliance evidence workspace

This directory is for version-controlled templates and non-sensitive evidence indexes—not medical information, legal privileged material, secrets, audit-log exports, or penetration-test findings.

Suggested evidence index:

- Intended-use approval
- Data-flow diagram version
- Threat-model version
- Privacy impact assessment approval
- Dependency/SBOM artifact identifier
- Automated test run identifier
- Penetration-test approval status
- Apple declaration approval
- Google Play declaration approval
- Legal launch approval
- Release date and responsible approvers
